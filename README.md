# Academy Platform (учебный сайт)

Готовый учебный сайт с:
- админкой;
- кабинетом преподавателя (создание курсов, загрузка видео);
- кабинетом студента;
- оплатой курсов через MBank (демо-сценарий подтверждения платежа).

## Стек
- Python + Flask
- SQLite
- Flask-SQLAlchemy

## Запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

Сайт будет доступен на `http://localhost:8000`.

## Демо-аккаунты
Создаются автоматически при первом запуске:

- **Админ:** `admin@academy.local` / `admin123`
- **Преподаватель:** `teacher@academy.local` / `teacher123`
- **Студент:** `student@academy.local` / `student123`

## Роли и сценарии
### 1) Админ
- Просмотр пользователей, курсов и оплат.
- Публикация/снятие с публикации курсов преподавателей.

### 2) Преподаватель
- Создает курс (название, описание, цена).
- Загружает видеоуроки в курс (mp4/mov/avi/mkv/webm).

### 3) Студент
- Просматривает каталог опубликованных курсов.
- Покупает курс через страницу MBank.
- После успешной оплаты получает доступ к видеоурокам.

## Примечание про MBank
В проекте реализован **учебный mock-поток** оплаты MBank:
- создается заказ,
- отображается страница оплаты,
- кнопка подтверждения помечает заказ как `paid` и открывает доступ к курсу.

Чтобы подключить реальный API MBank, замените логику маршрута `/mbank/pay/<id>` на вызовы официального платежного шлюза и webhook-подтверждения.
